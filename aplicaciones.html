Aplicaciones en el ciclo de desarrollo

Cuatro tareas donde los asistentes de IA ya forman parte del trabajo diario. Cada una incluye un ejemplo y la verificación que debe hacer una persona.

Explora las tareas

Usa las pestañas o las flechas del teclado.

El asistente convierte una descripción en un primer borrador: funciones, clases, consultas SQL o estructuras de una página. Es útil sobre todo en tareas conocidas y repetitivas.

Instrucción

prompt
Escribe una función en JavaScript que reciba
un arreglo de notas y devuelva el promedio,
ignorando los valores que no sean números.

Código propuesto

promedio.js
function promedio(notas) {
  const validas = notas.filter(Number.isFinite);
  if (validas.length === 0) return 0;
  const suma = validas.reduce((a, b) => a + b, 0);
  return suma / validas.length;
}

Qué verificar: que cubra casos límite (arreglo vacío), que no use funciones inexistentes y que realmente haga lo pedido.

Al pegar un fragmento con su mensaje de error, el asistente puede explicar la causa y sugerir una corrección. Sirve también para entender código ajeno.

Código con error

sumar.js · devuelve NaN
function sumar(lista) {
  let total = 0;
  for (let i = 0; i <= lista.length; i++) {
    total += lista[i];
  }
  return total;
}

Corrección sugerida

sumar.js · corregido
function sumar(lista) {
  let total = 0;
  for (let i = 0; i < lista.length; i++) {
    total += lista[i];
  }
  return total;
}

Explicación del asistente: con <= el índice llega a lista.length, que está fuera del arreglo; lista[i] vale undefined y al sumarlo el total se convierte en NaN.

Qué verificar: que la explicación coincida con el error real y que la corrección no cree otro problema.

La IA redacta comentarios, descripciones de funciones, guías de uso y resúmenes de cambios para mantener la documentación al día con menos esfuerzo.

Sin documentar

area.js
function area(b, h) {
  if (b <= 0 || h <= 0) {
    throw new RangeError('Medidas inválidas');
  }
  return b * h;
}

Documentación generada

area.js
/**
 * Calcula el área de un rectángulo.
 * @param {number} b - Base (mayor que 0).
 * @param {number} h - Altura (mayor que 0).
 * @returns {number} Área en unidades cuadradas.
 * @throws {RangeError} Si b o h no son positivos.
 */

Qué verificar: que la documentación describa lo que el código hace de verdad, no lo que «debería» hacer.

Dado un fragmento de código, el asistente propone casos de prueba, incluidos los límites que a veces se olvidan: vacío, valores negativos o texto con tildes.

palindromo.test.js · estilo Jest
describe('esPalindromo', () => {
  test('reconoce una palabra simple', () =>
    expect(esPalindromo('radar')).toBe(true));

  test('ignora mayúsculas, espacios y tildes', () =>
    expect(esPalindromo('Anita lava la tina')).toBe(true));

  test('rechaza un texto que no lo es', () =>
    expect(esPalindromo('hola')).toBe(false));

  test('acepta la cadena vacía', () =>
    expect(esPalindromo('')).toBe(true));
});

Qué verificar: unas pruebas generadas por IA pueden dar una falsa sensación de seguridad si repiten los mismos supuestos del código. Una persona debe decidir qué casos importan.

Tres formas de trabajar con IA

Las herramientas cambian rápido; los tipos de uso se mantienen.

Tipos de herramientas de IA para programar
TipoCómo se usaEjemplos
Autocompletado en el editorSugiere la siguiente línea o bloque mientras se escribe.GitHub Copilot
Chat conversacionalSe hacen preguntas, se pegan errores y se pide explicar o reescribir código.ChatGPT, Claude, Gemini
Agentes de programaciónEjecutan tareas de varios pasos: leen archivos, editan, corren pruebas y corrigen.Claude Code, modo agente de Copilot, Cursor

La evidencia disponible sobre su efecto en la productividad es mixta: depende del tipo de tarea y de la experiencia de quien programa. Se analiza en Ventajas y riesgos.
