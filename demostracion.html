Demostración práctica

Escribe una instrucción, observa el código propuesto, ponlo a prueba y decide si lo aceptas. Así se ve el proceso de revisión que exige trabajar con IA.

Cómo usar la demostración

  1. Elige un ejemplo o escribe tu propia instrucción.
  2. Genera el código y léelo con calma.
  3. Revisa: ejecuta las pruebas y marca la lista de verificación.
  4. Decide: acepta o descarta el resultado. Puedes empezar de nuevo cuando quieras.

Importante: es una simulación educativa. No se conecta a un modelo real: reconoce cuatro tareas (factorial, correo, promedio y palíndromo) y muestra respuestas preparadas que incluyen errores intencionales, para practicar la revisión. Las pruebas sí se ejecutan de verdad en tu navegador.

Qué demuestra este ejercicio

  • Un código que «parece correcto» puede fallar en casos límite que no se ven a simple vista.
  • Las pruebas detectan errores, pero no sustituyen entender el código.
  • Corregir es un diálogo: el hallazgo de la revisión mejora la siguiente propuesta.
  • Aceptar o descartar el resultado es una responsabilidad humana.
